# 🌸 MOCKUP 08 — SAKURA PINK
> **Status:** 🟡 Draf / Templat Placeholder  
> **Tema Desain:** Nuansa malam musim semi di Kyoto dengan aksen kelopak merah muda  

---

## 🎨 DESIGN TOKEN & STYLE

*   **Latar Belakang Utama:** `#1A0A0F` (Ungu-merah muda sangat gelap)
*   **Warna Permukaan Kartu:** `#220010`
*   **Warna Aksen Utama:** `Colors.pinkAccent` (Merah muda sakura)
*   **Visual Style:** Sudut kartu membulat sangat halus dengan pendaran merah muda romantis tipis.

---

## 🧭 SISTEM NAVIGASI & LAYOUT

*   **Navigasi Utama:** Menu Tombol Melayang (*Floating FAB Menu*) di pojok kanan bawah.
    *   Dapat mekar (*bloom*) ke atas untuk memunculkan daftar menu saat ditekan.
*   **Layout Khas:** Layout Grid bata (*Masonry Layout*) dengan tinggi kartu bervariasi sesuai konten.

---

## 🧩 ANIMASI & INTERAKSI KHAS

*   **Bloom Fade Expansion:** Efek mekar kelopak bunga sakura saat submenu melayang FAB terbuka secara berurutan (*staggered animation*).
*   **Soft Glow Pulse:** Pendaran merah muda redup-terang yang lambat pada ikon status.
